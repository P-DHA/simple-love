# 简爱 Simple Love

双人安卓 App：被观察者推送【实时屏幕画面 + 当前前台应用名称 + 手动选择的相册照片】，观察者实时查看。配套 Node.js WebSocket 中转服务。

> **隐私声明（重要）**
> 本应用仅适用于**双方完全知情、自愿授权**使用。被观察者可随时断开连接、关闭全部权限。
> **禁止未经他人许可监控手机，私自监控属于违法行为。**
> 所有权限必须由被观察者**手动主动授予**，App 不能静默获取任何手机数据。

## 一、项目结构

```
Simple Love/
├── server/                       # 后端：Node.js WebSocket 服务
│   ├── package.json
│   └── server.js                 # 配对房间 + 消息转发（ws 库，端口 8080）
│
└── app/                          # 前端：Expo React Native 安卓 App
    ├── package.json
    ├── app.json                  # Expo 配置（包名、权限）
    ├── eas.json                  # EAS 云打包配置（preview=APK）
    ├── babel.config.js
    ├── index.js                  # 入口
    ├── App.js                    # 页面切换（首页/被观察者/观察者）
    ├── src/
    │   ├── theme.js              # 样式常量
    │   ├── config.js             # 服务器地址持久化、地址归一化、配对码生成
    │   ├── ws.js                 # WebSocket 封装
    │   └── screens/
    │       ├── HomeScreen.js     # 首页：隐私声明大字 + 两个角色按钮
    │       ├── WatcherScreen.js  # 被观察者：配对码/权限引导/采集上传/断开
    │       └── ObserverScreen.js # 观察者：实时画面/应用名/相册/断开
    └── modules/
        └── screen-capture/       # 本地原生模块（Expo Modules API）
            ├── index.js          # JS 接口
            ├── expo-module.config.json
            └── android/
                ├── build.gradle
                └── src/main/
                    ├── AndroidManifest.xml        # 前台服务/权限声明
                    └── java/expo/modules/screencapture/
                        ├── ScreenCaptureModule.kt     # 模块入口（JS API）
                        ├── ScreenCaptureService.kt    # MediaProjection 前台捕获服务
                        ├── CaptureHelperActivity.kt   # 拉起系统屏幕录制弹窗
                        └── FrameProvider.kt           # 最新帧缓存
```

技术栈：前端 Expo（React Native，SDK 52），后端 Node.js + ws 库。屏幕捕获通过 MediaProjection（系统原生弹窗授权），前台应用检测通过 UsageStatsManager（使用情况访问权限），相册通过 expo-image-picker（手动选择）。

## 二、环境安装步骤

### 1. 安装 Node.js（后端必需）

1. 打开 https://nodejs.org/ 下载 **LTS 版本**（18 或 20 均可）。
2. Windows 安装包一路下一步即可（自带 npm）。
3. 验证安装（打开新的 PowerShell/CMD）：

```bash
node -v
npm -v
```

### 2. 启动 WebSocket 后端（电脑本地，端口 8080）

```bash
cd server
npm install
npm start
```

看到以下输出即成功：

```
[时间] 简爱 Simple Love WebSocket 服务已启动: ws://0.0.0.0:8080
[时间] 局域网地址: ws://192.168.x.x:8080  (手机与本电脑连同一WiFi时可用)
```

- 默认端口 **8080**，想换端口：`set PORT=9090 && npm start`（PowerShell 用 `$env:PORT=9090; npm start`）。
- **Windows 防火墙**：第一次启动时如弹出“是否允许 Node.js 访问网络”，点【允许】（专用网络和公用网络都勾上）。
- 手动放行：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 8080 → 允许连接。
- 服务停止（Ctrl+C）后所有连接会断开；**使用期间电脑必须保持开机**。

### 3. 手机 App 侧

见下方“四、Expo 项目依赖安装”与“五、EAS 云打包”。

## 三、内网穿透使用教程（ngrok，手机流量远程访问）

手机不在同一 WiFi 时，需要把电脑的 8080 端口暴露到公网。

1. **注册**：打开 https://dashboard.ngrok.com/ 注册免费账号。
2. **下载**：在 https://ngrok.com/download 下载 Windows 版，解压得到 `ngrok.exe`。
3. **配置 authtoken**（Dashboard 的 "Your Authtoken" 页面复制）：

```bash
ngrok config add-authtoken 你的token
```

4. **启动隧道**（先确保后端 `npm start` 在运行）：

```bash
ngrok http 8080
```

5. 面板会出现类似地址：

```
Forwarding  https://a1b2-xx-xx-xx-xx.ngrok-free.app -> http://localhost:8080
```

6. **App 里填**：把 `https://a1b2-xx-xx-xx-xx.ngrok-free.app` 填进 App 的“后端服务器地址”即可（App 会自动转成 `wss://`）。也可以手动写 `wss://a1b2-xx-xx-xx-xx.ngrok-free.app`。
7. 注意：
   - **ngrok 免费版链接每次重启都会变**，变了要重新填到 App。
   - 免费版有连接数/带宽限制，自用足够。
   - ngrok 免费版打开时可能弹一个浏览器确认页（只影响浏览器访问，App 的 WebSocket 不受影响）。

## 四、Expo 项目依赖安装命令

前置：已安装 Node.js；建议再安装手机端“Expo Go”用于简单调试（注意：**Expo Go 里测不了屏幕捕获和前台应用检测**，原生功能必须用 EAS 打包后的 APK）。

```bash
cd app
npm install
npx expo install --fix   # 自动把 expo 系列依赖对齐到 SDK 52 对应版本
```

开发调试（网页/基础功能）：

```bash
npx expo start
```

> 屏幕捕获、使用情况权限是原生模块，**必须走 EAS 云打包成 APK 后在真机安装测试**。

## 五、EAS 云打包 APK 完整步骤（无需 Android Studio）

1. **安装 EAS CLI**（任选其一）：

```bash
npm install -g eas-cli
```

2. **注册/登录 Expo 账号**：https://expo.dev/ 免费注册，然后：

```bash
cd app
eas login
eas whoami
```

3. **初始化项目**（会自动生成 projectId 写入 app.json）：

```bash
eas init
```

4. **云打包 APK**（preview 配置 = 直接出 APK）：

```bash
eas build -p android --profile preview
```

5. 等待云端构建（免费队列一般几分钟到十几分钟）。完成后终端给出下载链接，也可以在 https://expo.dev/ 项目页找到。
6. **安装 APK**：把链接发到手机浏览器下载，或直接下载后传到手机；安装时允许“安装未知来源应用”。
7. 常用命令：

```bash
eas build:list                 # 查看构建记录
eas build -p android --profile preview --auto-submit-with-profile=preview
```

> 后续改了代码：重新执行第 4 步即可。`versionCode` 需要递增时改 app.json 里的 `android.versionCode`。

## 六、安卓系统权限说明与限制（均为手动授权，App 不静默获取）

| 权限 | 用途 | 如何开启 | 限制 |
| --- | --- | --- | --- |
| 使用情况访问权限 | 读取当前前台应用名称 | 被观察者页点【去设置】→ 跳转系统“使用情况访问权限”→ 找到“简爱”→ 手动打开开关 | **必须去系统设置手动开启**，App 无法弹窗代办；部分国产 ROM 开机/更新后可能被重置 |
| 屏幕录制（MediaProjection） | 获取实时屏幕画面 | 被观察者页点【开启捕获】→ 弹出**系统原生屏幕录制弹窗**→ 手动点【立即开始】 | **每次开启都要手动授权**，重启 App/重启捕获都要重新点；用户也可随时从系统状态栏停止共享 |
| 相册读取 | 手动选择照片发送 | 被观察者页点【选择照片发送】→ 弹出系统相册权限弹窗手动允许 → 系统相册选择器里手动挑图 | **需要手动授权**；App 只上传你手动选中的图片，绝不自动扫描/上传 |
| 通知权限（Android 13+） | 屏幕共享前台服务的常驻通知 | 首次开启屏幕捕获时系统可能询问，可拒绝（不影响功能，只是通知栏不显示） | 可选 |

被观察者随时点【断开连接】：立即停止屏幕捕获、停止读取应用信息、停止上传数据并清空本地状态。观察者断开则清空所有已接收画面与图片。

## 七、使用流程

1. 电脑：`cd server && npm start`（或 ngrok 穿透，见第三节）。
2. 两部手机都装 APK 并打开 → 首页阅读隐私声明 → 各自选角色。
3. **被观察者**：填服务器地址 → 【生成配对码并连接】→ 屏幕显示 6 位配对码 → 按引导开启“使用情况访问权限”→ 点【开启捕获】并在系统弹窗点允许 → （可选）选择相册照片发送。
4. **观察者**：填同一服务器地址 → 输入 6 位配对码 → 【连接】→ 实时查看屏幕画面、当前应用名、收到的照片。
5. 任一方点【断开连接】即结束；被观察者断开会同步停止一切采集。

## 八、限制说明

- **电脑必须保持开机**才能运行 WS 服务；电脑关机/睡眠/断网，双方都会掉线。
- **不做内网穿透时只能同一 WiFi 使用**：App 里填电脑局域网地址（如 `ws://192.168.1.5:8080`），且手机与电脑必须在同一路由器下（注意路由器“AP隔离/访客网络”会挡住互访）。
- **ngrok 免费版链接会过期/变化**：每次重启 ngrok 地址都会变，需要重新填到 App；长时间无连接也可能被回收。
- 屏幕画面约 1~2 帧/秒（720p JPEG，省流量设计），适合“看状态”而非高帧率投屏。
- 手机锁屏后系统可能限制采集，画面会停在锁屏或暂停更新（取决于厂商 ROM）。
- 屏幕方向固定为捕获开始时的方向，中途旋转屏幕画面比例可能暂时不对。
- 本项目仅限自用，禁止用于任何未经对方知情同意的场景。

## 九、故障排查清单

### 1. 连接失败 / 一直“正在连接”
- [ ] 后端是否在运行？电脑上 `npm start` 窗口有没有报错？
- [ ] 地址是否填对？同 WiFi 用 `ws://电脑局域网IP:8080`（在 `ipconfig` 里看 IPv4 地址）；远程用 ngrok 的 `https://` 或 `wss://` 地址。
- [ ] 地址结尾不要带 `/`；端口必须一致（默认 8080）。
- [ ] Windows 防火墙是否放行 Node.js / 8080 端口（见第二节）。
- [ ] 是否同一路由器？路由器开了“AP 隔离/访客网络”会导致手机 ping 不通电脑。
- [ ] ngrok 重启过吗？地址变了要重新填。
- [ ] 电脑睡眠了？关闭睡眠或使用时保持唤醒。
- [ ] 观察 App 内“● 服务”小圆点：灰色说明 WebSocket 没连上，先解决服务连通性。

### 2. 屏幕画面不显示 / 黑屏 / 卡住
- [ ] 被观察者是否点了【开启捕获】并在**系统弹窗**点了【立即开始】？（状态点变绿、通知栏出现“简爱正在共享屏幕”）
- [ ] **必须用 EAS 打包的 APK**，Expo Go 里屏幕捕获不可用。
- [ ] 被观察者页面是否显示“已连接/观察者已上线”？没连上服务器画面不会发。
- [ ] 观察者页面是否显示“被观察者在线”？对方离线时画面停格属于正常。
- [ ] 首帧需要 1~3 秒；之后约 1 秒 1~2 帧，静止屏幕不会频繁刷新（有变化才推新帧）。
- [ ] 若对方从系统状态栏停止了投屏，画面会停在最后一帧，请让对方在 App 内重新【开启捕获】。
- [ ] 个别 ROM 省电策略杀后台服务：给“简爱”设置无限制省电/允许后台运行。

### 3. 读取不到应用名称（一直“未获取到”）
- [ ] **使用情况访问权限**是否已在系统设置里打开？去被观察者页③点【去设置】检查“简爱”开关是否为开。
- [ ] 部分国产 ROM（MIUI/EMUI/ColorOS 等）在“权限”列表里可能把该权限藏在特殊位置，或在重启后重置——重新打开一次。
- [ ] 权限刚打开后等几秒（App 每 4 秒自动复查一次状态点）。
- [ ] 某些系统应用（桌面/输入法）可能不产生事件，属于正常。

### 4. 照片发送失败 / 对方看不到照片
- [ ] 相册权限是否允许？（弹窗拒绝过的话，去系统设置 → 应用 → 简爱 → 权限 → 照片和视频 → 允许）
- [ ] 照片是否过大被跳过？发送后 App 会提示“跳过 N 张（过大或读取失败）”，换小图或降低数量重试。
- [ ] 网络太差时大图上传慢，等待几秒；观察者端照片在页面底部网格中，点击可放大。

### 5. 其他
- [ ] “连接被新设备接管”：同一角色重复连接会顶掉旧连接，属正常设计。
- [ ] 服务器控制台有实时日志（加入房间/断开/销毁），排错优先看日志。
- [ ] 修改前端代码后：开发期 `npx expo start` 摇一摇重载；正式使用需重新 `eas build`。
